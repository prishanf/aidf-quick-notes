Quick Notes — shared design mockup

Single throwaway prototype for the notes home screen (create, list, edit, delete). Fabricated data, no backend. Markup will not be reused — only the shared token layer crosses into the real app. Future UI features must extend this folder, not copy a new scaffold.

Screens

  • Notes Create form + list + inline edit + delete confirm + Markdown Write/Preview toggle

States

Every design-gate state is reachable by a click (URL ?state=).
