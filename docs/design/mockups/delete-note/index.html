Delete a note — design mockup

Throwaway prototype for the Feature 2 design gate. Fabricated data, no backend. Markup will not be reused — only the shared token layer crosses into the real app.

Screens

  • Notes Create form + list + per-row delete with confirm

States

Every state named in the design doc is reachable by a click.

State Open
Success (32 notes + Delete) open
Confirm dialog open, then Delete on a row
Delete in progress confirm Delete — watch “Deleting…”
Delete server error open, then confirm Delete
Delete not found (404) open, then confirm Delete
Empty (incl. after last delete) open or delete until empty
Loading open
Server error (load) open
Permission error open
Validation error submit with an empty title

What to exercise

  • Is Delete visible on each row without crowding title/body/timestamp?
  • Does the confirm dialog name the note and make Cancel vs Delete obvious?
  • After confirm, does the note leave the list? After the last note, empty state?
  • delete-error / delete-missing: is the alert clear and are other notes untouched?
  • Narrow below 40rem: dialog and list still usable?
  • Keyboard: tab to Delete, confirm Cancel/Delete, visible focus?
  • Reset fixtures after deletes — does the list restore?
