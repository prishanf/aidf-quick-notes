Create and list notes — design mockup

Throwaway prototype for the design gate. Fabricated data, no backend. Markup will not be reused — only the shared token layer crosses into the real app.

Every state named in the design doc is reachable by a click.

What to exercise

  • Is the create form + list readable as one composition on a laptop viewport?
  • With 32 notes, can you scan titles and timestamps without feeling crowded?
  • Narrow below 40rem: does the form and list stack cleanly without sideways page scroll?
  • Submit an empty title — is the error next to the field and announced?
  • Empty, loading, and error states: is recovery clear?
  • Tab through the form with the keyboard — is focus visible?
  • Reset fixtures after adding a note — does the list restore?
